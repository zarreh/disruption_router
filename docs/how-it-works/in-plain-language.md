# In plain language

The Disruption Router reads a logistics problem report — a delayed shipment, a
cancellation, bad weather, a capacity shortage — and tells the operations team
what to do next.

It does not guess. It looks up the relevant policies from a typed rulebook,
uses a language model to draft a recommendation, checks that recommendation
against the policies it actually found, and asks a human for approval when the
 stakes are high.

Every recommendation includes the exact policy clauses that support it, so the
decision can be audited.
